# Z1-04 相容邊界與 Phase 5 移除清單

本清單是舊公開 import 的治理登記。Phase 1 僅允許保留薄 shim：shim
只發出 `DeprecationWarning` 並 re-export canonical symbol，不重新定義
class、Enum、Decision 或 Evidence，也不得改變 canonical 行為。

## 預定移除清單

| old_path | target_canonical | deprecation_version | planned_removal_phase |
|---|---|---|---|
| `zhiyan_legal.runner` | `zhiyan_legal.engine` | `v3.0.0` | `Phase 5` |
| `backend.engine` | `zhiyan_legal.engine` | `v3.0.0` | `Phase 5` |
| `committee_core` | `committee.policies`, `committee.reasoning` | `v3.9.5` | `Phase 5` |
| `committee_core.policies` | `committee.policies` | `v3.9.5` | `Phase 5` |
| `committee_core.policies.governance_contract` | `committee.policies.governance_contract` | `v3.9.5` | `Phase 5` |
| `committee_core.reasoning` | `committee.reasoning` | `v3.9.5` | `Phase 5` |
| `committee_core.reasoning.debate_engine` | `committee.reasoning.debate_engine` | `v3.9.5` | `Phase 5` |
| `committee_core.reasoning.scraping_engine` | `committee.reasoning.scraping_engine` | `v3.9.5` | `Phase 5` |

## 移除規則

這些檔案在 Phase 1–4 不得直接刪除。Phase 5 移除前，必須先檢查消費者、
更新 migration guide，並將 `tests/contract/test_backward_imports.py` 的
相容性契約改為確認舊路徑已正式停止支援。

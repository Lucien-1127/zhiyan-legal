## Compatibility decisions

- The old Judgment module contains no independent runtime definitions after this change; its public names resolve to the canonical classes by identity.
- Legacy committee statuses that have no one-to-one canonical equivalent are conservatively mapped: `DELETED`/`NONEXISTENT` → `CONFLICT`, `AMENDED` → `STALE`, and operational/error states → `UNVERIFIED`.
- Judgment evidence uses the judgment date as a deterministic `retrieved_at` fallback because the old schema does not carry retrieval metadata. Callers can provide the actual retrieval timestamp.

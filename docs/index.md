# 智研：讓法律回答更容易核對

智研是一套台灣法律研究助手。它的目標不是代替律師，而是幫一般人先把問題說清楚、找到可能相關的法規與判決，並分辨哪些內容有依據、哪些仍需要確認。

## 為什麼要用智研

一般人遇到法律問題時，最困難的往往不是找不到一段回答，而是不知道：

- 這段回答根據什麼？
- 引用的法條或判決是否真的支持結論？
- 資料不足時，系統是不是仍在猜？
- 這件事是否已經需要律師、法院或主管機關介入？

智研因此遵守三個原則：

1. **看得懂**：先用一般用語整理問題與法律重點。
2. **查得到**：有來源時保留法規、判決及原文定位。
3. **不硬猜**：事實或來源不足時，明確要求補充資料或建議人工確認。

> 智研提供研究與資訊整理，不構成法律意見。涉及訴訟期間、重大財產、刑事責任或人身安全時，請儘速諮詢合格律師或主管機關。

## 可以拿來做什麼

- 初步理解一個法律名詞或常見程序。
- 整理事件時間、人物與待確認事實。
- 查找可能相關的法條、裁判與來源位置。
- 檢查回答中哪些主張已有證據、哪些仍待查。
- 把資料整理成較容易交給律師或承辦人確認的內容。

## 使用方式

請盡量提供「發生了什麼、何時發生、你已有哪些文件、想解決什麼問題」。例如：

> 我在 3 月 5 日收到公司終止契約通知，工作兩年，沒有收到資遣費。我想知道下一步要準備什麼資料。

比起只輸入「公司可以開除我嗎」，完整事實更能降低誤判。

## 開發者快速開始

```bash
git clone https://github.com/Lucien-1127/zhiyan-legal.git
cd zhiyan-legal
bash scripts/setup.sh

source .venv/bin/activate
zhiyan-legal "什麼是公然侮辱罪？" --dry-run
```

`dry-run` 不會呼叫外部模型，適合先確認安裝、路由與輸出格式。
